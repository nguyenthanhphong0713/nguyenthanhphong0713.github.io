3 Trọng Tâm Chuyên Môn Cốt Lõi

Kinh nghiệm thực tiễn đúc kết từ vai trò Tech Project Manager và kiến trúc hệ thống ERP doanh nghiệp.

Microsoft SQL Server

  • Viết Stored Procedure, Function tính toán số liệu sổ sách kế toán, công nợ, xuất nhập tồn.
  • Tối ưu hóa câu lệnh query chậm, xem xét Execution Plan, đánh Index bảng chứng từ lớn.
  • Kiểm soát tính toàn vẹn dữ liệu qua Stored Procedure & nghiệp vụ: khóa sổ kế toán, kiểm tra tồn kho âm, kiểm soát điều kiện ghi sổ.
  • Bảo trì cơ sở dữ liệu: sao lưu (backup), phục hồi (restore), kiểm tra phân mảnh bảng.

Arito ERP & Fast ERP

  • Thành thạo cấu trúc XML Metadata (định nghĩa danh mục, màn hình chứng từ, trường dữ liệu, validation).
  • Lập trình kịch bản xử lý sự kiện giao diện, kiểm soát tính hợp lệ của dữ liệu nhập liệu trên màn hình và tính toán tự động số liệu chứng từ.
  • Lập trình báo cáo quản trị, bảng cân đối số phát sinh, sổ cái, báo cáo bán hàng, báo cáo công nợ.
  • Chỉnh sửa logic tính toán và quy trình duyệt chứng từ theo từng bài toán đặc thù của doanh nghiệp.

Tự Xây Dựng Extension

  • Tự phát triển Extension cho SSMS & Visual Studio bằng C# (.NET / VSSDK) để giải quyết các điểm nghẽn năng suất.
  • Viết các script tự động hóa bằng Python/PowerShell phục vụ trích xuất, chuyển đổi dữ liệu kế toán và tài liệu.
  • Không chỉ dừng ở việc dùng công cụ có sẵn mà chủ động code thêm công cụ để công việc chạy nhanh và chuẩn hơn.

Lumi SQL Formatter & Smart Snippets

Bài toán thực tế: Viết lệnh T-SQL trong SSMS phải bấm hoa thường thủ công, code dài khó đọc; các công cụ thương mại bên ngoài thì nặng nề hoặc tốn phí bản quyền.
  • Tự động viết HOA hơn 510 từ khóa, hàm và kiểu dữ liệu T-SQL ngay khi bấm Space, Enter, Tab.
  • Sử dụng Lexer phân tích cú pháp chuẩn của Microsoft ScriptDom: Tuyệt đối không làm đổi chữ trong chuỗi string ('...'), chú thích comment, hoặc tên bảng trong ngoặc vuông ([...]).
  • Bung Snippet tức thì (viết `ssf` -> bung thành `SELECT * FROM $CURSOR$` đặt sẵn con trỏ), tạo nhanh snippet bằng phím tắt `Ctrl+Alt+S`.
  • Tích hợp thẳng vào Tools -> Options của SSMS, hỗ trợ giao diện Dark/Light.

VISUAL STUDIO VSIX VS 2017 | 2019 | 2022

LumiIntellisense (XML Metadata ERP)

Bài toán thực tế: Hệ thống ERP (Arito, Fast) nhúng code JavaScript trong thẻ <js> của file XML. Visual Studio chỉ hiểu đây là XML thuần nên không hề có gợi ý cú pháp, lập trình viên phải nhớ chay toàn bộ tên hàm.
  • Tự động bắt sự kiện gõ trong khối thẻ <js><![CDATA[ ... ]]></js> để bật bảng autocomplete IntelliSense.
  • Tự động phân tích các tệp kịch bản trong hệ thống để nạp danh sách các hàm vòng đời và xử lý nghiệp vụ của ERP.
  • Hỗ trợ gợi ý cú pháp đầy đủ cho các phương thức thao tác Form, Grid dữ liệu và bộ hàm tiện ích dùng chung của hệ thống ERP.
  • Chạy 100% trong bộ nhớ RAM, tự cập nhật khi file JS thay đổi (Hot-Reload) mà không làm lag Visual Studio.
